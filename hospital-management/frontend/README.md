# Frontend - MedCare AI

The frontend is a lightweight Single Page Application (SPA) structure served by the Flask backend.

## Structure

*   **`index.html`**: The main entry point.
*   **`js/`**:
    *   `main_v4.js`: Contains the core application logic, event listeners, and API calls.
*   **`css/`**:
    *   `styles.css`: Custom styling and layout rules.

## Technologies
- **TailwindCSS** (via CDN) for utility-first styling.
- **Plotly.js** (via CDN) for data visualization.
- **Vanilla JS** for DOM manipulation and state management.
